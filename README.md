# Extreme-Value-Theory
This project demonstrates how to try to model the "Black Swan" events - rare, high-impact occurances that traditional normal distributions fail to capture. All this is done using *scipy.stats.genextreme*. 

#### Key Concepts Explored
GEV; GEV Parameters (ξ, μ, σ); return periods; quantiles; pdf & cdf; Inverse Survival Functions (ISF)


Examples from live events where genextreme can be used:
- *genextreme.isf* works on exactly the same logic in which global institutions prepare for tail events like Black Monday, Subprime Mortgage Crisis, and Flash crashes. This is also heavily to calculate 100 year events for storms, wildfires, earthquakes or any natural disasaters. 
- *PDFs and CDFs* are used to do parametric testing for portfolio risks and hazard defence systems.
